# Design record

Reader: a technical buyer or developer assessing a small business application's local SSO path. Use: inspect a synthetic sign-in, recoverable draft, and gated preview against a real local Keycloak provider. Voice: direct technical English.

Reference inspected: the published [Tenant Request Portal](https://github.com/skyon0522-ai/tenant-request-portal/blob/e835a9047054510c74bf936cb8c1628719e64551/README.md), its [request page source](https://github.com/skyon0522-ai/tenant-request-portal/blob/e835a9047054510c74bf936cb8c1628719e64551/app/src/app/%28app%29/page.tsx) and [layout styles](https://github.com/skyon0522-ai/tenant-request-portal/blob/e835a9047054510c74bf936cb8c1628719e64551/app/src/app/%28app%29/index.scss). Reused the reference's local-demo identity, short page hierarchy, native labeled form controls, separate identity and work areas, live status/error regions, visible focus, responsive single-column mobile layout, and preserved draft on failure. The role-picker login model and its CSS dependency were not reused. The source interaction pattern was also compared with the pinned Keycloak adapter guide; its updateToken example is changed here so the catch path blocks and returns before the protected operation.

The page presents local identity first, then a synthetic draft, then the client-side gate. The only app-persisted value is the explicit synthetic draft, scoped to this tab. The official adapter owns its in-memory tokens and one-time callback state. The action validates the real UserInfo subject against the adapter subject before making an explicitly synthetic in-memory counter increment. This demo does not implement server authorization.

Editable sources: `public/index.html`, `public/app.css`, `public/app.js`, `server/app.js`. On narrow screens, work sections stack; controls remain labeled and keyboard operable. Status and error messages use live regions. Reduced-motion is respected and no animation is used. Verification results are recorded in the root README; this design record does not claim a screenshot review.
